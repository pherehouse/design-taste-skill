## S01 瑞士/国际主义风格（Swiss / International Typographic Style）

- 核心视觉特征：严格网格、无衬线字体、左对齐、大量留白、客观信息优先
- 配色：黑白 + 单一强调色（常见红）
- 排版与构图：模块化网格，非对称平衡，强层级
- 字体：Helvetica/Akzidenz/Inter 类无衬线；中文 思源黑体、阿里巴巴普惠体
- 质感/图像：平面无肌理，摄影/几何图形为主
- 可借鉴手法：先定 8/12 栏网格再放内容；标题字号≥正文 3 倍；只用一种强调色【通】
- 典型用途/适用场景：企业品牌、展览海报、年报、信息设计、作品集网站
- 代表参考网站：[D&AD](https://www.dandad.org/)（已访问核验）；[The One Show & ADC](https://www.oneclub.org/)（已访问核验）；[Tokyo TDC](https://tokyotypedirectorsclub.org/)（已访问核验）；[Siteinspire](https://www.siteinspire.com/)（已访问核验）；[Minimal Gallery](https://minimal.gallery/)（已访问核验）；[Typewolf](https://www.typewolf.com/)（已访问核验）；[Fonts In Use](https://fontsinuse.com/)（已访问核验）；[Butterick's Practical Typography](https://practicaltypography.com/)（已访问核验）；[Utopia](https://utopia.fyi/)（已访问核验）；[Savee](https://savee.com/)（已访问核验）；[Brand New](https://www.underconsideration.com/brandnew/)（已访问核验）
- 依据：通识；文章中 Siteinspire（网格筛选）、Fonts In Use、Tokyo TDC 相关

## S02 极简主义（Minimalism）

- 核心视觉特征：少即是多，大留白，元素极少，靠字号对比和比例撑画面
- 配色：黑白灰 + 极少量点缀色
- 排版与构图：单栏/大留白，居中或网格，内容稀疏
- 字体：细/常规无衬线或优雅衬线；中文 思源黑体 Light、思源宋体
- 质感/图像：干净，无装饰
- 可借鉴手法：删到不能再删；留白≥50%；用字重和字号而不是颜色做层级【通】
- 典型用途/适用场景：高端产品、作品集、科技品牌、生活方式品牌
- 代表参考网站：[Awwwards](https://www.awwwards.com/)（已访问核验）；[CSS Design Awards](https://www.cssdesignawards.com/)（已访问核验）；[Apple Design Awards](https://developer.apple.com/design/awards/)（已访问核验）；[D&AD](https://www.dandad.org/)（已访问核验）；[Mobbin](https://mobbin.com/)（已访问核验）；[Refero](https://refero.design/)（已访问核验）；[Laws of UX](https://lawsofux.com/)（已访问核验）；[Siteinspire](https://www.siteinspire.com/)（已访问核验）；[One Page Love](https://onepagelove.com/)（已访问核验）；[Minimal Gallery](https://minimal.gallery/)（已访问核验）；[Rauno Freiberg](https://rauno.me/)（已访问核验）；[Google Fonts](https://fonts.google.com/)（已访问核验）；[Are.na](https://www.are.na/)（已访问核验）；[Cosmos](https://www.cosmos.so/)（已访问核验）；[Savee](https://savee.com/)（已访问核验）；[Brand New](https://www.underconsideration.com/brandnew/)（已访问核验）

## S03 粗野主义（网页）（Brutalism (Web)）

- 核心视觉特征：原始 HTML 感、系统字体、裸露边框、反精致、刻意粗糙
- 配色：默认色：纯白/纯黑/系统蓝链接，或高对比原色
- 排版与构图：打破网格，堆叠，信息裸露
- 字体：等宽/系统字体、Times；中文 宋体/黑体系统字
- 质感/图像：无，或低保真截图
- 可借鉴手法：保留浏览器默认样式与系统字体；用粗边框和原色制造态度【通】
- 典型用途/适用场景：艺术家主页、独立刊物、先锋工作室、实验活动
- 代表参考网站：[Hoverstat.es](https://www.hoverstat.es/)（已访问核验）；[Are.na](https://www.are.na/)（已访问核验）
- 依据：通识 + 文章（Hoverstat.es 收录另类网页）

## S04 新粗野主义（Neo-brutalism）

- 核心视觉特征：粗黑描边、硬投影（无模糊）、高饱和色块、圆角卡片、俏皮
- 配色：明黄/粉/薄荷/天蓝 + 纯黑描边
- 排版与构图：卡片块状、贴纸感、错位叠放
- 字体：粗几何无衬线（Clash Display、Satoshi Bold 等）；中文 站酷高端黑、阿里巴巴普惠体 Heavy
- 质感/图像：平涂 + 硬阴影
- 可借鉴手法：2–3px 纯黑描边 + 4–6px 无模糊位移阴影；色块不超过 3 种【通】
- 典型用途/适用场景：年轻化 SaaS、创作者工具、活动页、社媒图
- 代表参考网站：[Recent（原 Godly）](https://recent.design/)（已访问核验）；[Fontshare](https://www.fontshare.com/)（已访问核验）；[tweakcn](https://tweakcn.com/)（已访问核验）
- 依据：通识；文章 Fontshare（Clash Display）相关

## S05 包豪斯（Bauhaus）

- 核心视觉特征：基本几何（圆/方/三角）、三原色、功能主义、构成感
- 配色：红黄蓝 + 黑白
- 排版与构图：几何构成，对角线与网格并用
- 字体：几何无衬线（Futura 类）；中文 方正兰亭黑、思源黑体 Bold
- 质感/图像：平面色块
- 可借鉴手法：只用圆方三角三种图形和三原色做构成；对角线制造动势【通】
- 典型用途/适用场景：文化活动海报、品牌图形系统、家居品牌
- 代表参考网站：[Ordinary Folk](https://www.ordinaryfolk.co/)（已访问核验）；[Brand New](https://www.underconsideration.com/brandnew/)（已访问核验）
- 依据：通识；文章 Ordinary Folk（2D 几何动效）相关

## S06 孟菲斯（Memphis）

- 核心视觉特征：波点、波浪线、锯齿、撞色几何碎片、玩味
- 配色：糖果色撞色 + 黑
- 排版与构图：散点拼贴、随机几何装饰
- 字体：圆润粗体；中文 站酷快乐体、庞门正道粗书体
- 质感/图像：图案化填充
- 可借鉴手法：几何碎片散点 + 波点/波浪图案；黑色细线收边防止过乱【通】
- 典型用途/适用场景：潮玩、儿童/青少年、快消促销、活动视觉
- 代表参考网站：[Golden Wolf](https://www.goldenwolf.tv/)（已访问核验）
- 依据：通识；文章 Golden Wolf 高饱和撞色相关

## S07 Y2K / 千禧复古（Y2K）

- 核心视觉特征：铬金属、液态气泡、像素/早期 Web 元素、未来感乐观
- 配色：银色、冰蓝、荧光粉紫、渐变
- 排版与构图：拼贴、星形装饰、早期网页框
- 字体：宽体/像素字/科技字；中文 庞门正道标题体、像素字体
- 质感/图像：金属反光、塑料透明、低像素
- 可借鉴手法：铬金属字 + 星形闪光 + 低像素窗口元素；冰蓝/荧光粉渐变【通】
- 典型用途/适用场景：潮牌、音乐、美妆、年轻社媒视觉
- 代表参考网站：[Promonews](https://www.promonews.tv/)（已访问核验）；[Web Design Museum](https://www.webdesignmuseum.org/)（已访问核验）
- 依据：通识 + 文章（Web Design Museum：Y2K 一手史料）

## S08 玻璃拟态（Glassmorphism）

- 核心视觉特征：半透明磨砂层、背景模糊、细亮边框、浮层层次
- 配色：鲜艳渐变底 + 白色半透明
- 排版与构图：浮动卡片叠层
- 字体：现代无衬线（SF Pro、Inter）；中文 苹方、思源黑体
- 质感/图像：磨砂玻璃、柔光
- 可借鉴手法：背景模糊 20–40px、白色 10–25% 透明、1px 半透明亮边【通】
- 典型用途/适用场景：App UI、科技发布页、仪表盘、iOS 风格界面
- 代表参考网站：[Apple Design Awards](https://developer.apple.com/design/awards/)（已访问核验）；[Apple 人机界面指南（HIG）](https://developer.apple.com/design/human-interface-guidelines/)（已访问核验）；[Spotted in Prod](https://www.spottedinprod.com/)（已访问核验）
- 依据：通识；文章 Apple HIG/ADA 相关（未在访问中核验其具体视觉）

## S09 新拟态（Neumorphism）

- 核心视觉特征：同色背景上的柔和凸起/凹陷，双向软阴影
- 配色：低饱和浅灰/米白单色
- 排版与构图：卡片/按钮浮雕
- 字体：圆润无衬线；中文 思源黑体
- 质感/图像：柔和阴影
- 可借鉴手法：同底色双阴影（亮左上暗右下）；仅用于少量控件，注意对比度【通】
- 典型用途/适用场景：智能家居控制、计算器类小工具、概念 UI
- 代表参考网站：文章未收录对应资源（缺口）
- 依据：通识

## S10 扁平设计（Flat Design）

- 核心视觉特征：去阴影去纹理、纯色、简洁图标、清晰可用
- 配色：明快纯色系
- 排版与构图：网格卡片、图标化
- 字体：无衬线；中文 思源黑体、HarmonyOS Sans
- 质感/图像：无
- 可借鉴手法：统一图标线宽与圆角；纯色块 + 清晰层级【通】
- 典型用途/适用场景：App/网页 UI、信息图、讲解动画
- 代表参考网站：[BUCK](https://buck.co/)（已访问核验）；[Oddfellows](https://oddfellows.tv/)（已访问核验）；[Ordinary Folk](https://www.ordinaryfolk.co/)（已访问核验）；[Mobbin](https://mobbin.com/)（已访问核验）；[Figma Community](https://www.figma.com/community)（已访问核验）；[Material Design 3](https://m3.material.io/)（已访问核验）；[The Component Gallery](https://component.gallery/)（已访问核验）；[Google Fonts](https://fonts.google.com/)（已访问核验）

## S11 拟物化（Skeuomorphism）

- 核心视觉特征：模拟真实材质（皮革、金属、木纹）、光影立体
- 配色：写实材质色
- 排版与构图：仿实物界面
- 字体：多样；中文 系统字体
- 质感/图像：真实肌理、高光、阴影
- 可借鉴手法：真实材质贴图 + 高光阴影；适合需要强「可触摸感」的界面【通】
- 典型用途/适用场景：游戏 UI、音乐/乐器软件、怀旧主题
- 代表参考网站：[Game UI Database](https://www.gameuidatabase.com/)（已访问核验）；[Web Design Museum](https://www.webdesignmuseum.org/)（已访问核验）
- 依据：通识 + 文章（Web Design Museum：拟物化按钮史料；Game UI Database）

## S12 复古/怀旧（Retro / Vintage）

- 核心视觉特征：做旧纸张、网点印刷、复古字体、年代配色
- 配色：米黄、橄榄、锈红、褪色色调
- 排版与构图：徽章、标签、对称版式
- 字体：衬线/手写/装饰体；中文 方正清刻本悦宋、汉仪尚巍手书
- 质感/图像：颗粒、噪点、印刷错版
- 可借鉴手法：加纸纹/颗粒/网点；用年代字体与褪色配色【通】
- 典型用途/适用场景：餐饮、精酿、咖啡、手作品牌、复古海报
- 代表参考网站：[Web Design Museum](https://www.webdesignmuseum.org/)（已访问核验）；[Fonts In Use](https://fontsinuse.com/)（已访问核验）；[Pinterest](https://www.pinterest.com/)（已访问核验）

## S13 编辑/杂志风（Editorial / Magazine）

- 核心视觉特征：大标题衬线、多栏排版、图文张力、版面节奏
- 配色：克制中性色 + 一个品牌色
- 排版与构图：多栏网格、出血大图、引言放大
- 字体：衬线标题 + 无衬线正文；中文 思源宋体/方正标雅宋 + 思源黑体
- 质感/图像：摄影主导
- 可借鉴手法：衬线大标题 + 多栏正文 + 引言放大；摄影出血【通】

## S14 日式/无印风（Japanese / Muji）
