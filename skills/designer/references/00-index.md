## 回答时怎么用

1. 先读本索引（`00-index.md`），明确用户需求属于哪类（海报/品牌/产品/网页/UI/社媒/电商）。
2. 用 `03` 末尾「按设计类型的快速选型」+ 表 A/B 圈定 2–3 个候选风格。
3. 读 `02` 或 `05` 对应风格卡片，给出视觉特征、配色、字体建议。
4. 从风格卡片的「参考网站」或 `04` 的标签索引挑 3–5 个网站推荐；推荐前查看 `01` 中的核验状态：
   - `无法访问` 的站点不推荐或明确提示；`仅凭文章描述` 的站点要说明未核验；标「付费」的要提示。
5. 需要混搭时读 `06`；需要出图时读 `07` 给提示词。
6. 回答中注明依据：哪些来自文章、哪些是通用设计知识、哪些是推测。

## 来源与核验规范

- 站点清单一级来源：Eian（@EianLu）X 文章《100 个提升审美的设计网站大赏》，https://x.com/EianLu/status/2121219503988113557 ，2026-11-14 通过 X 公开读取接口获取全文。本包不收录原文全文，请直接查阅原帖。
- 产出本知识库所用的五轮分析提示词来自 OSen（@OxygenOvO2）：https://x.com/OxygenOvO2/status/2121559894717509850 。
- 核验状态（网站）：
  - `已访问核验`：2026-11-14 访问返回 2xx/3xx 且有真实内容（curl；被反爬拦截的用 WebFetch 复查）。
  - `无法访问`：站点本身报错/下线，附状态码。
  - `仅凭文章描述`：被拦截未能取到内容，描述仅来自文章。
- 依据标记（结论）：【文】文章原文；【访】本次访问页面所得；【通】通用设计知识；「推测」无数据支撑的受众/效果判断。
- 当前统计：100 个网站，已访问核验 97、无法访问 1（Realtime Colors，HTTP 402 Deployment Paused）、仅凭文章描述 2（Behance 动态专区、ArtStation）。
- 未登录任何网站，未下载任何付费资源。
