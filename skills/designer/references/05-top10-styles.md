# 05 · 十大精选风格（深度卡片）

选择依据：①在本库 100 个网站中有较多对应参考资源（文章集中于网页/UI/视频，故偏向数字风格）；②覆盖海报、品牌、产品、网页、UI、社媒、电商七类常见需求；③补入文章缺失但中文用户常用的「新中式」。入选是编者判断，不是数据排名。
依据标记：【通】通用设计知识；【文】来自 EianLu 文章；【访】本次访问核验。色值为示例建议【通】，不是任何品牌官方色。受众均为「推测」。
中文字体说明：思源黑体/思源宋体（Noto Sans/Serif SC）、霞鹜文楷为开源可商用；阿里巴巴普惠体、HarmonyOS Sans、MiSans 为厂商免费字体（商用前请自行确认最新授权条款）；方正/汉仪/站酷等字体授权各不相同，**商用前务必核对授权**。

---

## 1. 极简主义 Minimalism（S02）

- 定义：用最少的元素、最大的留白，靠比例、字号对比和材质传达品质。【通】
- 核心元素：大留白、单一视觉焦点、细字重、克制的网格、高质量摄影。
- 配色：`#FFFFFF` `#F5F5F4` `#1C1C1C` + 一个点缀色（如 `#C2410C`）。
- 字体：英文 Inter / Neue Montreal 类；中文 思源黑体 Light/Regular、思源宋体（偏文艺时）。
- 适用场景：高端数码与家居产品页、作品集、品牌官网、包装、小红书封面。
- 潜在受众（推测）：25–45 岁追求品质的城市白领、设计从业者。
- 优点：耐看、不易过时、突出产品；限制：信息量低，国内电商详情页需补充卖点；做不好会显得空和冷。
- Do：先删再加；用字重/字号建立层级；留白至少占画面一半。Don't：为「填满」加装饰；用 3 种以上颜色；正文字号过小导致可读性差。
- 参考网站：[Minimal Gallery](https://minimal.gallery/)（文章：学黑白灰、大留白、字号对比【文】；已访问核验）、[Siteinspire](https://www.siteinspire.com/)（页面有 Minimal 筛选【访】）、[Savee](https://savee.com/)、[Laws of UX](https://lawsofux.com/)（自身图文卡片干净【文】）。

## 2. 瑞士/国际主义 Swiss / International（S01）

- 定义：20 世纪中叶瑞士发展出的网格化、客观、无衬线的平面设计体系。【通】
- 核心元素：模块化网格、左对齐、无衬线、大标题、几何图形或黑白摄影、非对称平衡。
- 配色：`#FFFFFF` `#111111` `#E30613`（经典红）或单一亮色。
- 字体：Helvetica / Akzidenz-Grotesk / Inter；中文 思源黑体 Bold、阿里巴巴普惠体。
- 适用场景：企业 VI、展览/讲座海报、年报、信息图、建筑/设计事务所官网。
- 潜在受众（推测）：专业人士、B2B 决策者、文化与设计圈。
- 优点：信息清晰、专业可信、系统化易延展；限制：情感温度低，大众消费品可能显得冷淡。
- Do：先建 8/12 栏网格；字号阶梯用比例计算（可用 [Utopia](https://utopia.fyi/)）。Don't：居中对齐堆叠；中文字距不调导致松散。
- 参考网站：[Fonts In Use](https://fontsinuse.com/)、[Tokyo TDC](https://tokyotypedirectorsclub.org/)、[D&AD](https://www.dandad.org/)、[Brand New](https://www.underconsideration.com/brandnew/)、[Siteinspire](https://www.siteinspire.com/)（Grid Layout 筛选【访】）。

## 3. 克制产品风（Linear / Vercel 式）Refined Product UI（S28）

- 定义：以真实产品可用性为先、系统化灰阶与精确间距、几乎无装饰的现代 SaaS 界面风格。【文+通】
- 核心元素：12 级灰阶色板、4/8px 间距、1px 细边框、轻量动效（150–250ms）、清晰的状态设计。
- 配色：中性灰阶（Radix gray 1–12）+ 单一品牌色，如 `#5E6AD2` 类蓝紫。
- 字体：Inter / Geist / Satoshi；中文 思源黑体、HarmonyOS Sans、MiSans。
- 适用场景：SaaS 官网与后台、开发者工具、B 端数据看板、效率类 App。
- 潜在受众（推测）：开发者、知识工作者、B 端采购。
- 优点：可信、专业、可规模化；限制：容易千篇一律，品牌记忆点弱。
- Do：用 [Radix Colors](https://www.radix-ui.com/colors) 定色阶；按 [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines) 与 [Impeccable](https://impeccable.style/) 自查去「AI 味」【文】。Don't：深色背景 + 发光边框 + 光束特效的 AI 创业套路（文章点名【文】）；卡片套卡片。
- 参考网站：[coss ui](https://coss.com/ui)、[awesome-design-md](https://github.com/VoltAgent/awesome-design-md)、[Mobbin](https://mobbin.com/)、[Nicelydone](https://nicelydone.club/)、[Emil Kowalski](https://emilkowal.ski/)、[tweakcn](https://tweakcn.com/)。

## 4. 深色科技风 Dark Mode Tech（S21）

- 定义：深黑/深灰底、高对比文字、细线层级与少量发光强调的科技感界面与视觉。【通】
- 核心元素：近黑底（非纯黑）、6–12% 白色细边框分层、等宽数字、单一霓虹强调色、微弱噪点。
- 配色：`#0A0A0A` `#141414` `#262626` `#EDEDED` + 强调 `#22D3EE` 或 `#A3E635`。
- 字体：Geist / Inter / JetBrains Mono；中文 思源黑体、HarmonyOS Sans。
- 适用场景：AI/开发者产品官网、数码发布 KV、金融科技、游戏外设电商图。
- 潜在受众（推测）：22–40 岁开发者、科技爱好者。
- 优点：专业、聚焦、产品截图更突出；限制：长文阅读疲劳，过多发光显廉价（文章 Dark Mode Design 条目提醒【文】）。
- Do：用亮度差而不是阴影分层；强调色只给 CTA。Don't：纯黑底配纯白大段正文；满屏光效。
- 参考网站：[Dark Mode Design](https://www.darkmodedesign.com/)、[Recent](https://recent.design/)、[Nicelydone](https://nicelydone.club/)、[React Bits](https://reactbits.dev/)、[Radix Colors](https://www.radix-ui.com/colors)（含深色配色【文】）。

## 5. Bento 网格 Bento Grid（S24）

- 定义：像便当盒一样用大小不等的圆角卡片拼出模块化信息版面。【文（作者示例提到「深色的 Bento 网格卡片」）+通】
- 核心元素：统一圆角（16–24px）、统一间距、每格一个信息点、大小对比制造节奏、卡片内图标/截图/大数字。
- 配色：浅色版 `#F4F4F5` 底 + `#FFFFFF` 卡；深色版 `#0B0B0C` 底 + `#161618` 卡；卡片内少量品牌色。
- 字体：Satoshi / General Sans（[Fontshare](https://www.fontshare.com/) 免费【文】）/ Inter；中文 MiSans、思源黑体。
- 适用场景：产品功能介绍页、发布会总结页、个人主页、社媒信息图、电商卖点图。
- 潜在受众（推测）：科技产品用户、产品经理。
- 优点：信息密度高又有秩序，适配响应式；限制：已被大量使用，需在内容和插图上做差异。
- Do：最多 2–3 种卡片尺寸；最重要卖点放最大格。Don't：每格塞满文字；圆角不统一。
- 参考网站：[Framer Gallery](https://www.framer.com/gallery/)、[Landingfolio](https://www.landingfolio.com/)、[SaaSFrame](https://www.saasframe.io/)、[Recent](https://recent.design/)。

## 6. 新粗野主义 Neo-brutalism（S04）

- 定义：在粗野主义的「直白」上加入高饱和色块、粗黑描边和无模糊硬阴影的俏皮数字风格。【通】
- 核心元素：2–3px 纯黑描边、4–6px 位移硬阴影、贴纸式卡片、超粗标题、手绘箭头/星星。
- 配色：`#FFE14D` `#FF8FAB` `#7DF9C0` `#7AB8FF` + `#000000`。
- 字体：Clash Display / Satoshi Black（Fontshare【文】）；中文 站酷高端黑、阿里巴巴普惠体 Heavy。
- 适用场景：年轻化 SaaS/创作者工具落地页、活动页、社媒海报、校园品牌。
- 潜在受众（推测）：18–30 岁学生、创作者、独立开发者。
- 优点：记忆点强、成本低、社媒抓眼；限制：不适合高端/严肃行业，长期使用易疲劳。
- Do：描边和阴影参数全站统一；颜色 ≤3 种。Don't：叠加渐变和柔阴影（风格冲突）。
- 参考网站：[Recent](https://recent.design/)、[tweakcn](https://tweakcn.com/)（可调 shadcn 主题阴影/圆角【文】）、[Hoverstat.es](https://www.hoverstat.es/)（粗野/另类网页源头）。

## 7. 编辑/杂志风 Editorial（S13）

- 定义：借鉴印刷杂志版式的多栏网格、衬线大标题与摄影叙事。【通】
- 核心元素：衬线大标题、栏宽控制（每行约 45–75 字符【文：Practical Typography 讲行长】）、引言放大、出血大图、页码/栏目标签。
- 配色：`#FAF8F3` 纸色 `#1A1A1A` 墨色 + 品牌色 `#B91C1C`。
- 字体：英文 衬线（如 GT Sectra/Playfair 类）+ 无衬线正文；中文 思源宋体 / 方正标雅宋 标题 + 思源黑体 正文。
- 适用场景：内容品牌官网、时尚/文化专题、品牌画册、公众号长图、年报。
- 潜在受众（推测）：25–50 岁知识型读者、时尚文化受众。
- 优点：权威感、有品位、适合长内容；限制：对内容质量与摄影要求高，移动端多栏需重排。
- Do：用 [Typewolf](https://www.typewolf.com/) 查衬线+无衬线搭配【文】。Don't：文章点名的 AI 套路「斜体衬线大标题」滥用（见 Impeccable【文】）。
- 参考网站：[It's Nice That](https://www.itsnicethat.com/)、[Fonts In Use](https://fontsinuse.com/)、[Practical Typography](https://practicaltypography.com/)、[One Page Love](https://onepagelove.com/)。

## 8. 电影感 Cinematic（S25）

- 定义：借用电影摄影的画幅、布光、调色与构图，营造叙事与情绪。【文（7 个电影参考站）+通】
- 核心元素：2.39:1 宽画幅或黑边、主光方向明确、暗部压黑、浅景深、胶片颗粒、留白字幕式排字。
- 配色：青橙 `#0F3B4C` + `#E39B5B`；或低饱和冷调 `#1E2A33` `#8FA3AD`。
- 字体：宽字距大写细衬线/无衬线；中文 思源宋体 Light、方正兰亭细黑。
- 适用场景：电影/剧集海报、汽车与户外品牌 KV、视频封面、品牌片分镜、AI 视频提示词。
- 潜在受众（推测）：大众；品牌形象诉求。
- 优点：情绪强、显高级；限制：信息承载少，电商转化图不宜通用。
- Do：先在 [StillsLab](https://stillslab.com/)/[Flim](https://flim.ai/) 按光线、色彩找 3–5 张参考帧再定调【文】；写提示词用 [StudioBinder](https://www.studiobinder.com/blog/ultimate-guide-to-camera-shots/) 的镜头术语【文】。Don't：只靠滤镜不管布光；字体过多破坏画面。
- 参考网站：[ShotDeck](https://shotdeck.com/)（付费）、[FILMGRAB](https://film-grab.com/)、[American Cinematographer](https://theasc.com/)、[Ciclope Festival](https://www.ciclopefestival.com/)、[EyeCannndy](https://eyecannndy.com/)。

## 9. 新中式 Neo-Chinese（S15）

- 定义：提炼中国传统美学（山水、书法、纹样、器物、色彩）并以现代版式与极简手法重构。【通】
- 核心元素：大面积留白、书法或宋体标题、竖排、印章、抽象云纹/回纹/窗棂、框景构图、宣纸或水墨肌理。
- 配色：朱砂 `#C0392B`、黛青 `#2E4A5A`、月白 `#E8EEF0`、琥珀金 `#C9A063`、墨 `#1F1F1F`（传统色名仅作描述）。
- 字体：思源宋体、方正清刻本悦宋、霞鹜文楷、汉仪尚巍手书（标题），正文 思源黑体。
- 适用场景：茶/白酒/中式糕点包装、文旅海报、国潮服饰、春节/中秋节日营销、中餐品牌。
- 潜在受众（推测）：25–55 岁文化中产、18–30 岁国潮消费者。
- 优点：文化认同强、节日营销天然适配；限制：符号堆砌易俗套，海外传播需解释。
- Do：只选 1–2 种传统元素并抽象化；用现代网格约束。Don't：龙凤祥云金红全上；书法字用于大段正文。
- 参考网站：**缺口**——文章未收录中式专门资源。可间接参考 [Tokyo TDC](https://tokyotypedirectorsclub.org/)（东亚字体海报【文】）、[Pinterest](https://www.pinterest.com/)、[Savee](https://savee.com/)；建议用户补充站酷、花瓣等中文资源（需注明来源）。

## 10. 3D / 黏土风 3D Clay（S19）

- 定义：用柔软圆润的 3D 体块、棚拍柔光和材质质感塑造亲和或高质感的视觉。【通】
- 核心元素：圆角倒角、软阴影、马卡龙或写实 PBR 材质、简洁背景、景深。
- 配色：`#FFD6E0` `#C9F2E7` `#FFF1B8` `#B8C6FF`（黏土版）；产品写实版依材质。
- 字体：圆润无衬线；中文 阿里巴巴普惠体、HarmonyOS Sans Rounded 类、站酷快乐体（玩味时）。
- 适用场景：App 插图与空状态、电商主图、产品 KV、动态海报、3D 图标。
- 潜在受众（推测）：15–35 岁年轻大众用户。
- 优点：亲和、吸睛、AI 生成效果稳定；限制：制作成本高（手作），风格泛滥易廉价。
- Do：用 [Poly Haven](https://polyhaven.com/) 免费 CC0 HDRI 打光【文】；统一材质与光源方向。Don't：材质过多、塑料感太强、阴影方向不一致。
- 参考网站：[ArtStation](https://www.artstation.com/)（仅凭文章描述）、[Sketchfab](https://sketchfab.com/)、[ManvsMachine](https://mvsm.com/)、[BUCK](https://buck.co/)、[Pwnisher](https://www.youtube.com/@pwnisher)、[80 Level](https://80.lv/)。
