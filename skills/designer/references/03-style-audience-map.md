# 03 · 风格 ↔ 受众 / 行业 / 场景对照表

来源与依据：本表**没有任何用户调研或市场数据支撑**，受众、年龄、情绪印象等全部是基于通用设计知识与行业惯例的判断，统一标「推测」。原文章（EianLu《100 个提升审美的设计网站大赏》）不涉及受众分析。风格定义见 `02-styles-visual-features.md`。

使用规则：向用户推荐时必须说明「这是经验判断，不是数据结论」；如果用户提供了真实受众数据，以用户数据为准，并把新结论连同来源补进本表。
